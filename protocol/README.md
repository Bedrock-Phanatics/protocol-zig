# Protocol schema

| File | Purpose |
| --- | --- |
| `schema/bedrock.json` | Canonical wire schema for the supported release. Generated by `tools/codegen ingest`; everything in `src/generated` is generated from it. |
| `schema/reconciliation.json` | The pinned [protocolgen](https://github.com/bedrock-mc/protocolgen) revision, path and file digests, plus reviewed decisions layered over its manifest: packet names, directions, removed IDs, enum restrictions, invariants, custom codecs and documented source conflicts. Every decision cites evidence and fails ingest if the manifest it was written against changes. |
| `schema/actor-refs.json` | Reviewed classification of every 64-bit integer field as an actor `runtime` ID, an actor `unique` ID or `other`. Generation fails on any unclassified or stale entry, so a new actor reference cannot be missed. |
| `schema/sample-hints.json` | Test-only hints that keep generated corpus samples inside what the gophertunnel oracle accepts. They never affect the schema or codecs. |

Ingest checks every pinned digest and that the manifest targets exactly the
reconciliation's Minecraft version and protocol number.

## Moving to the next stable release

Only stable releases are supported, and only one at a time.

1. Keep the current schema to diff against: `cp protocol/schema/bedrock.json /tmp/old.json`.
2. In `schema/reconciliation.json`, set `target`, `manifest.revision`,
   `manifest.path` and the four `manifest.files` digests (sha256 of the
   committed files) for the new protocolgen output.
3. Rebuild the schema. Ingest fails on every decision that no longer matches;
   review each one against the new evidence.

   ```sh
   go -C tools/codegen run . ingest -root ../.. -manifest /path/to/protocolgen
   go -C tools/codegen run . diff /tmp/old.json ../../protocol/schema/bedrock.json
   ```

4. Regenerate (stale generated files are deleted), rebuild the corpus and
   check coverage. Generation names every new 64-bit field missing from
   `schema/actor-refs.json`; classify each one before continuing.

   ```sh
   go -C tools/codegen run . generate -root ../..
   go -C tools/codegen run . corpus -root ../..
   go -C tools/codegen run . coverage -root ../..
   ```

5. Bump the gophertunnel oracle in `tools/differential`, then run
   `go -C tools/differential run .` and `zig build test`. Every accepted
   divergence must still occur or be removed.
